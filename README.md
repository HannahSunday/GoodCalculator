# Good Calculator

**最簡易的二代健保接案試算**

接案金額打進去，二代健保補充保費、實收金額自動跳出來。

---

## 這個工具幫你做什麼

- 輸入接案金額，自動判斷有沒有達到二代健保補充保費起扣門檻（NT$29,500）
- 自動算出補充保費（費率 2.11%）
- 手機、電腦都能開，即時計算，不用按送出
